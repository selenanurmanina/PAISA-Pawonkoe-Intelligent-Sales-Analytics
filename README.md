# PAISA — Pawonkoe Sales Analytics

**PAISA** is a web-based dashboard developed to support sales analysis and business decision-making for Pawonkoe, an UMKM business.

The dashboard combines sales forecasting using **XGBoost** and **customer sentiment analysis** to help users understand sales trends, predict future sales, and explore customer feedback.

## Features

- **Sales Forecasting** — Predicts future sales using the XGBoost machine learning algorithm.
- **Sentiment Analysis** — Analyzes customer sentiment to provide insights into customer feedback.
- **Word Cloud Visualization** — Displays frequently occurring words in customer feedback.
- **Data Upload** — Supports uploading sales and review data in CSV or Excel formats.
- **Interactive Dashboard** — Presents analysis results through visualizations and an interactive interface.

## Objectives

- Help Pawonkoe analyze historical sales data.
- Provide sales predictions to support business planning.
- Identify customer sentiment and recurring themes in customer feedback.
- Support data-driven decision-making for UMKM business development.

## Getting Started

### Prerequisites

Make sure Python is installed on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/USERNAME/paisa-pawonkoe-sales-analytics.git
   ```

2. Navigate to the project directory:

   ```bash
   cd paisa-pawonkoe-sales-analytics
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the dashboard using Streamlit. Replace `GUI.py` if the main application file has a different name.

   ```bash
   streamlit run GUI.py
   ```

## Project Workflow

1. Upload the relevant sales and customer review data.
2. Process the data for analysis.
3. Generate sales forecasts using XGBoost.
4. Analyze customer sentiment and visualize frequently occurring words.
5. Review the results through the PAISA dashboard.
